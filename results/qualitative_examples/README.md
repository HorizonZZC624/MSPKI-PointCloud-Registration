# Figure 6 and Supplementary Figure S2 source records

These eight NPZ files contain the four displayed point-cloud pairs, with one file per method. The SUN3D and 7-Scenes files are the saved indoor seed-7351 visualization inputs. The `seq09_ref40_src25_*.npz` files were re-extracted from the current KITTI seed-7351 best checkpoints at 100% source-point retention and mask seed 9017. The `seq09__ref428_src418_*.npz` files are the saved second KITTI example used only in Supplementary Figure S2.

The two `*_metrics.json` records give the single-pair KITTI metrics, checkpoint identifiers, and test-pair index for the re-extracted main figure case. The `*_provenance.json` files record all plotted IR, RRE, and RTE values and their corresponding plotted NPZ files. Figure 6 uses these single-pair values; the manuscript's complete-test and three-training-seed KITTI statistics continue to use the separate `data/registration_evaluation/` records. Small differences between a standalone pair inference and the archived complete-test run must not be combined into one statistic.

The archived NPZ and provenance records retain the displayed inputs and annotations. The current output palette uses dark blue for the reference cloud, ochre for the transformed source cloud, solid green for inlier matches, and dashed red for outlier matches. Each panel uses at most 10,000 points per cloud and the 70 highest-score correspondences. The full correspondence sets, rather than the displayed subset, determine IR. The inlier threshold is 0.1 m for the indoor cases and 1.0 m for KITTI.
